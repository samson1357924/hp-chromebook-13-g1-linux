# HP Chromebook 13 G1 (Google Chell) Linux

Complete Linux support for **HP Chromebook 13 G1** (Board: `chell`, Skylake-Y) — AVS audio, keyboard hwdb, power/EC tuning.

* **First pitfall**: Installer requires [Safe Graphics / nomodeset](pitfalls/01-safe-graphics-nomodeset.md)

| Board | `chell` (lars family) |
| Processor | m7-6Y75 / m5-6Y57 / m3-6Y30 |
| GPU | HD 515 (`i915`) |
| Audio | AVS SSM4567 + NAU8825 + DMIC |
| Wi-Fi | 7265 AC |
